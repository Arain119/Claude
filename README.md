# 星见岛 · 小信使的生活

一座可以自由探索的写实海岛小镇，第三人称视角，玩法参考 GTA 式开放世界。你是岛上邮局新来的小信使：每天去邮局领信，走路、骑车或开车穿过商店街、樱川河堤、田野、环岛公路、狐守神社、港口和灯塔岬，把信送到收信人手里，同时过好自己的小日子。

## 画面

- 照片级材质：沥青、石板、砖墙、瓦屋顶、树皮、草地、岩石等 20 多种贴图由生图模型生成，法线贴图在运行时由贴图推算。
- 物理天空（Preetham 大气散射）、云层、星空、月亮，天空实时生成环境反射；ACES 色调映射、泛光、暗角和调色。
- 地形四层混合（草 / 土 / 岩 / 沙），陡坡用三平面投影避免拉伸；海面与河面反射天空。
- 3D 模型：12 种居民（含小信使本人）和 8 种车船由 Tripo 文本生成 3D 模型，再经减面与贴图压缩；角色按身体部位切分后接入骨骼动画，可以走、跑、坐、钓鱼、挥手、打电话。
- 实例化森林（樱花、杉、黑松、阔叶树，最多 3200 棵）带风吹摇摆；夜里路灯在地面投下光斑。

## 玩法

- **送信**：每天早上去邮局找方姐领信，交给居民本人或投进信箱，可以拿到小费（贝壳币）和好感。
- **主线「灯塔与面包」**：面包房的小满和灯塔守人林澈靠你传信。
- **开车**：走到车旁按 F 上车（右舵、左侧通行），环岛公路上有车流、公交站、加油站和山顶观景台。车有引擎声、喇叭和碰撞。
- **生活**：买面包、咖啡、和菓子和花；在栈桥钓鱼卖给鱼铺；在沙滩捡贝壳；给居民送礼；回家睡觉进入新的一天（自动保存）。
- **地图**：左下角是随朝向旋转的小地图；按 Tab 打开大地图，点地点可快速前往，点空白处设置导航点。

## 操作

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| WASD | 行走 / 驾驶 | Shift | 奔跑 |
| 鼠标 | 环视 | 滚轮 | 镜头远近 |
| 空格 | 跳跃 / 手刹 | E | 互动 |
| F | 上车 / 下车 | H | 喇叭 |
| T | 切换时间 | 1–9 | 快速前往 |
| Tab | 地图 | B / J | 背包 / 手账 |
| U | 隐藏界面 | M | 静音 |

手机上：左半屏拖动行走，右半屏拖动环顾，右下角按钮负责互动、跳跃、跑步和上下车。设置里可以切换高 / 中 / 低画质。

## 运行

游戏会加载 `assets/` 里的贴图和模型，所以需要通过本地服务器打开（直接双击 HTML 文件时浏览器会拦截加载）：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 开发

源码按模块放在 `src/`，用 Node 打包成单文件：

```bash
node build.mjs            # 生成 index.html（独立网页）和 dist/hoshimi-island.html（Artifact 版本）
python3 tools/glb2json.py # Artifact 不托管 .glb，把模型转成内嵌 glTF JSON 放到 dist/assets/
```

| `05_buildings.js` | 民居、可进入的小信使之家、学校、公园 |

| `11_vehicles.js` | 车辆模型、交通 AI、驾驶物理 |
| `12_game.js` | 时间与光照、玩家、第三人称镜头、交互、商店、存档 |
