# 星见岛 · 小信使的生活

一座可以自由探索的动漫风海岛小镇（东西约 430 m、南北约 360 m，镇子占岛的大半）：世界的尺度、道路、车流和生活细节按真实小镇来做，画面则是新海诚、京阿尼式的动画质感。第三人称视角，玩法参考 GTA 式开放世界。你是岛上邮局新来的小信使：每天去邮局领信，走路、骑车或开车穿过商店街、樱川河堤、水田、海边公路、狐守神社、港口和灯塔岬，把信送到收信人手里，同时过好自己的小日子。

## 画面

- 手绘动画背景风格的材质：沥青、石板、砖墙、瓦屋顶、树皮、草地、岩石等 20 多种贴图由生图模型按动画美术风格生成，法线贴图在运行时由贴图推算。
- 动漫天空：在物理大气散射的基础上提高饱和度，天顶是深钴蓝；积云边缘清晰、受光面亮白、背光面偏蓝紫，黄昏时变成金橙与紫色。
- 动漫调色：画面更鲜艳，暗部偏冷、亮部偏暖，配合柔光泛光。
- 角色：12 种居民（含小信使本人）由 Tripo 生成动漫风 3D 模型，自动切分身体部位并绑定成蒙皮骨骼，使用两阶赛璐璐着色和描边；能走、跑、坐、钓鱼、挥手、打电话。对话头像由模型实时渲染。
- 车辆与船同样使用赛璐璐着色和描边；整个世界还有一层屏幕空间描边（深度轮廓 + 折角线），建筑、地形与道具和角色同一种线稿风格。
- 草地：玩家周围约 19 万根 GPU 草叶（高画质），沿风向推进的阵风会掀起明暗起伏的"草浪"；草叶根部取地面草色、草尖偏黄绿。镇内是修剪过的矮草坪，河堤中等高度，山坡与野地才有成片高草和零星野花。道路、人行道、建筑处通过俯视覆盖图自动避开。
- 树：枝干按树种生长，树冠由若干团叶簇组成。每团是一个起伏的实心簇体（贴着密密的花 / 叶纹理，填满空隙、压出暗部），表面再贴一层按真实尺寸绘制的叶片卡（樱花约 6 cm 一朵、樟叶约 10 cm），边缘自然不被切断。光照法线在"簇自身"与"整个树冠"之间混合，远看明暗成大块，近看每团仍有体积；受光面暖黄绿、背光面冷蓝绿，樱花暗部偏淡紫，逆光时叶片透亮。染井吉野是伞形扁平花层，樟树圆润，黑松是一层层扁平针叶团，杉树是锥形。
- 空气透视：远处偏蓝、朝太阳方向偏暖，低处（山谷、海面）雾更浓，高处更通透；大地上有随风移动的云影。
- 实例化森林（杉、黑松、阔叶树，约 2400 棵，远景用低面数簇体）带风吹摇摆：神社后山是杉与阔叶混交林，海岸是一圈防风黑松林；夜里路灯在地面投下光斑。

## 交通与地形

- **环线铁路**：复线环线全长约 950 m，最大坡度 30‰。北侧镇区直线段有岛式站台的樱丘站、两处平交道和跨河铁桥；东侧以低桥跨过港口出口（渔船从桥下进出）；南侧贴着沙滩走，是海边电车，樱花广场到沙滩有一处人行道口；西侧穿过水田。南岸汐见浜站、西岸稻穗站为相对式站台（站台、坡道、候车棚、站名牌）。两列电车反向运行、逐站停靠，接触网、防护栅栏沿线布置。
- **环岛公路**：从镇北路出发，跨过樱川、在西北角与铁路平交（警报灯、栏杆，车辆停车等候），沿水田西侧南下，再沿海岸向东接回港口路，与镇内道路连成一个大环。海岸段铁路在外侧临海，公路与铁路之间是白色波形钢板护栏。
- **地形约束**：路基按纵断面填挖并与地形融合；过河处自动改为桥，河堤栏杆与步道在桥位断开。
- **碰撞**：建筑、围墙、栅栏、柱子、长椅、售货机、树干、灌木都有碰撞体；人行道、台阶、站台是可以站上去的地面。隧道与桥面单独作为"地下 / 空中"地面处理，开车穿过隧道时镜头留在洞内。
- **植被摆放**：先俯视渲染一张"人造物占用图"，树木、灌木、草丛避开道路、铁路、人行道和建筑。
- **填空**：沿道路自动补齐住宅（每块地先检查道路、铁路、河道、水田和已有建筑），北路北侧是背靠后山的一排人家，广场东侧有便利店，港口东南角有渔家和船屋，沙滩上有海之家。

## 玩法

- **送信**：每天早上去邮局找方姐领信，交给居民本人或投进信箱，可以拿到小费（贝壳币）和好感。
- **主线「灯塔与面包」**：面包房的小满和灯塔守人林澈靠你传信。
- **开车**：走到车旁按 F 上车（右舵、左侧通行），环岛公路上有车流、公交站和加油站；神社东侧有石阶山道通往星见山顶的观景台。车有引擎声、喇叭和碰撞。
- **生活**：买面包、咖啡、和菓子和花；在栈桥钓鱼卖给鱼铺；在沙滩捡贝壳；给居民送礼；回家睡觉进入新的一天（自动保存）。
- **地图**：左下角是随朝向旋转的小地图；按 Tab 打开大地图，点地点可快速前往，点空白处设置导航点。

## 操作

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| WASD | 行走 / 驾驶 | Shift | 奔跑 |
| 鼠标 | 环视 | 滚轮 | 镜头远近 |
| 空格 | 跳跃 / 手刹 | E | 互动 |
| F | 上车 / 下车 | H | 喇叭 |

手机上：左半屏拖动行走，右半屏拖动环顾，右下角按钮负责互动、跳跃、跑步和上下车。设置里可以切换高 / 中 / 低画质。

## 运行

游戏会加载 `assets/` 里的贴图和模型，所以需要通过本地服务器打开（直接双击 HTML 文件时浏览器会拦截加载）：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 开发

源码按模块放在 `src/`，用 Node 打包成单文件：

```bash
node build.mjs            # 生成 index.html（独立网页）和 dist/hoshimi-island.html（Artifact 版本）
python3 tools/glb2json.py # Artifact 不托管 .glb，把模型转成内嵌 glTF JSON 放到 dist/assets/
```
