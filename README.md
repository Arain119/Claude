# 星见岛 · 小信使的春天

一座可以自由行走的动漫风樱花小岛。你是岛上邮局新来的小信使：去方姐那里领信，穿过商店街、樱川河堤、狐守神社、港口和灯塔岬，把每一封信送到收信人手里。

整个游戏是一个单独的 HTML 文件（`index.html`），只依赖 cdnjs 上的 three.js r128。所有模型、纹理、招牌、角色的脸和声音都由代码实时生成，不加载任何外部模型或图片。

## 玩法

- **送信**：每天早上去邮局找方姐领信。交给居民本人，或者投进对应人家的信箱，可以拿到小费（贝壳币），还能增加好感。
- **主线「灯塔与面包」**：面包房的小满和灯塔守人林澈靠你传信。送完三封信后，第三天晚上九点去樱花广场。
- **生活**：在商店街买面包、咖啡、和菓子和花；在栈桥钓鱼，把鱼卖给蓝鲸鱼铺；在沙滩捡贝壳；给居民送礼物；回家睡觉进入新的一天（会自动保存）。
- **小秘密**：神社的白狐、沙滩的漂流瓶、港口的橘猫、星愿井，还有 12 枚邮票等你收集。

## 操作

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| WASD | 行走 | Shift | 跑步 |
| 空格 | 跳跃 / 起身 | E | 互动 |
| F | 飞行 | V | 第一 / 第三人称 |
| T | 切换下午 / 黄昏 / 夜樱 | 1–9 | 传送到各地点 |
| Tab | 地图 | B / J | 背包 / 手账 |
| H | 隐藏界面 | M | 静音 |

手机上：左半屏拖动行走，右半屏拖动环顾，右下角按钮负责互动、跳跃、跑步和切换视角。设置里可以切换高 / 中 / 低画质。

## 场景

- 海风通商店街：20 家原创店铺，每家都有多行招牌（店名、英文名、电话）、扇形垂边条纹遮阳篷、凹入式店面和店前陈列。楼上有窗户、空调外机、晾衣阳台和天线。
- 街道细节：电线杆与电线、带横幅的路灯、节日灯笼串、黄色盲道、排水格栅、「止まれ」标志和公交站。
- 铁路：双轨、两处平交道（警灯交替闪烁、警铃、栏杆落下）、岛式站台的樱丘站。两节车厢的通勤电车会在站台停靠约 14 秒，透过车窗能看到车内的座椅和吊环。
- 樱花广场（百年樱花树、环形长椅、星愿井）、樱川河堤的花隧道、狐守神社（鸟居群、石灯笼、狐狸像、拜殿、手水舍、绘马、地藏、神木）、港口、灯塔岬、月牙沙滩。
- 30 位居民有各自的作息、台词和喜好。汽车会在平交道前停车等待。

## 开发

源码按模块放在 `src/`，用 Node 打包成单文件：

```bash
node build.mjs   # 生成 index.html（独立网页）和 dist/hoshimi-island.html（Artifact 版本）
```

| 文件 | 内容 |
|---|---|
| `00_core.js` | 数学与噪声、画质档位、几何合并（按材质 × 区块）、OBB 碰撞与坡道 |
| `01_materials.js` | 程序化纹理、窗户 / 招牌 / 遮阳篷图集 |
| `02_world.js` | 地形高度函数、海、河、天空着色器、远山 |
| `03_trees.js` | 染井吉野樱花树、绿树、黑松、草、花瓣粒子 |
| `04_town.js` | 商店街与街道设施 |
| `05_buildings.js` | 民居、可进入的小信使之家、学校、公园 |
| `06_rail.js` | 铁路、车站、平交道、列车 |
| `07_places.js` | 广场、河堤、神社、港口、灯塔岬、沙滩 |
| `08_chars.js` | 赛璐璐角色、发型、服装、动画、自行车、猫 |
| `09_npcs.js` | 居民数据、信件池、主线、邮票 |
| `10_audio.js` | Web Audio 环境音与八音盒 |
| `11_vehicles.js` | 汽车 |
| `12_game.js` | 时间与光照、玩家、交互、商店、事件、存档 |
| `13_ui.js` | HUD、地图、对话、面板 |
| `14_main.js` | 构建流程与主循环 |
