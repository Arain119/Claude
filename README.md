# 星见岛 · 小信使的生活

一座可以自由探索的动漫风海岛小镇：世界的尺度、道路、车流和生活细节按真实小镇来做，画面则是新海诚、京阿尼式的动画质感。第三人称视角，玩法参考 GTA 式开放世界。你是岛上邮局新来的小信使：每天去邮局领信，走路、骑车或开车穿过商店街、樱川河堤、田野、环岛公路、狐守神社、港口和灯塔岬，把信送到收信人手里，同时过好自己的小日子。

## 画面

- 手绘动画背景风格的材质：沥青、石板、砖墙、瓦屋顶、树皮、草地、岩石等 20 多种贴图由生图模型按动画美术风格生成，法线贴图在运行时由贴图推算。
- 动漫天空：在物理大气散射的基础上提高饱和度，天顶是深钴蓝；积云边缘清晰、受光面亮白、背光面偏蓝紫，黄昏时变成金橙与紫色。
- 动漫调色：画面更鲜艳，暗部偏冷、亮部偏暖，配合柔光泛光。
- 角色：12 种居民（含小信使本人）由 Tripo 生成动漫风 3D 模型，自动切分身体部位并绑定成蒙皮骨骼，使用两阶赛璐璐着色和描边；能走、跑、坐、钓鱼、挥手、打电话。对话头像由模型实时渲染。
- 车辆与船同样使用赛璐璐着色和描边；整个世界还有一层屏幕空间描边（深度轮廓 + 折角线），建筑、地形与道具和角色同一种线稿风格。
- 草地：玩家周围约 19 万根 GPU 草叶（高画质），沿风向推进的阵风会掀起明暗起伏的"草浪"；草叶根部取地面草色、草尖偏黄绿，田野里有成片的高草和零星野花。道路、人行道、建筑处通过俯视覆盖图自动避开。
- 树冠：按太阳方向分出暖黄绿的受光面和冷蓝绿的背光面，逆光时叶片透亮，外缘有轮廓光；樱花的暗部会偏淡紫。
- 空气透视：远处偏蓝、朝太阳方向偏暖，低处（山谷、海面）雾更浓，高处更通透；大地上有随风移动的云影。
- 实例化森林（樱花、杉、黑松、阔叶树，最多 3200 棵）带风吹摇摆；夜里路灯在地面投下光斑。

## 交通与地形

- **环岛铁路**：复线环岛线全长约 1.5 km，最大坡度 2.5%。镇区直线段有岛式站台的樱丘站、两处平交道和跨河铁桥；其余沿海岸绕岛一周，北岸有两座海岸隧道。北岸潮见崎站、西岸西浜站为相对式站台（站台、坡道、候车棚、站名牌）。两列电车反向运行、逐站停靠，接触网、防护栅栏沿线布置。
- **环岛公路**：沿海岸布线，铁路在外侧临海、公路在内侧；坡度不超过 8%，深挖处为隧道（洞门、照明、检修步道），高填处为桥。与铁路在西岸平交，道口有警报灯与栏杆，车辆会停车等候。护栏为连续的白色波形钢板护栏（圆立柱、端部外弯）。
- **地形约束**：路基按纵断面填挖并与地形融合；隧道上方保留覆土，明线段保持净空，两者冲突处形成陡峭的挡土切面。
- **碰撞**：建筑、围墙、栅栏、柱子、长椅、售货机、树干、灌木都有碰撞体；人行道、台阶、站台是可以站上去的地面。隧道与桥面单独作为"地下 / 空中"地面处理，开车穿过隧道时镜头留在洞内。
- **植被摆放**：先俯视渲染一张"人造物占用图"，树木、灌木、草丛避开道路、铁路、人行道和建筑。

## 玩法

- **送信**：每天早上去邮局找方姐领信，交给居民本人或投进信箱，可以拿到小费（贝壳币）和好感。
- **主线「灯塔与面包」**：面包房的小满和灯塔守人林澈靠你传信。
- **开车**：走到车旁按 F 上车（右舵、左侧通行），环岛公路上有车流、公交站、加油站和山顶观景台。车有引擎声、喇叭和碰撞。
- **生活**：买面包、咖啡、和菓子和花；在栈桥钓鱼卖给鱼铺；在沙滩捡贝壳；给居民送礼；回家睡觉进入新的一天（自动保存）。
- **地图**：左下角是随朝向旋转的小地图；按 Tab 打开大地图，点地点可快速前往，点空白处设置导航点。

## 操作

| 按键 | 作用 | 按键 | 作用 |
|---|---|---|---|
| WASD | 行走 / 驾驶 | Shift | 奔跑 |
| 鼠标 | 环视 | 滚轮 | 镜头远近 |

## 运行

游戏会加载 `assets/` 里的贴图和模型，所以需要通过本地服务器打开（直接双击 HTML 文件时浏览器会拦截加载）：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

## 开发

源码按模块放在 `src/`，用 Node 打包成单文件：

```bash
node build.mjs            # 生成 index.html（独立网页）和 dist/hoshimi-island.html（Artifact 版本）
python3 tools/glb2json.py # Artifact 不托管 .glb，把模型转成内嵌 glTF JSON 放到 dist/assets/
```
